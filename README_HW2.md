Q1: The worst-case time complexity of Bubble Sort is O(n²)

Q2: Bubble Sort repeatedly compares neighboring elements and may need to make many comparisons during each pass through the array. Because it uses nested loops to repeatedly compare elements, the number of operations can grow approximately as the square of the number of elements, resulting in O(n²) time complexity.

Q3: A 1,000-element array can require roughly 10,000 times as much comparison work as a 10-element array because Bubble Sort is O(n²).
